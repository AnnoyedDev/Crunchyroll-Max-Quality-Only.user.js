# Crunchyroll-Max-Quality-Only.user.js
Max quality only for Crunchyroll

# For non french user

# Install
1) Install TamperMonkey or ViolentMonkey.
2) Select crunchyroll-max-quality-only.user.js
3) Click "Raw"
4) Install
5) Done.
